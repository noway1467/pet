# 桌面宠物 (Desktop Pet) v3.9.6

这是一个功能丰富、高度可定制的 Windows 桌面宠物应用程序，基于 [PySide6](https://wiki.qt.io/Qt_for_Python) 开发。它不仅能在你的桌面上提供一个透明、无边框、可置顶的虚拟陪伴，还内置了物理引擎、多种宠物形态（像素、自定义图片、Live2D）、丰富的交互反馈、情感养成系统，以及结合系统 TTS 的语音播报功能。

## ✨ 核心特性

### 1. 多样化的渲染引擎
本项目支持三种不同类型的宠物形态，随时可以通过右键菜单或系统托盘进行切换：
* 👾 **像素宠物 (Pixel Pet)**：内置如史莱姆 (Slime)、猫咪 (Cat) 等程序化动画角色，支持“像素风”和“平滑风”两种渲染模式。
* 🖼️ **图片宠物 (Image Pet)**：支持加载本地的静态图片或动图 (PNG, JPG, WEBP, GIF 等)，支持水平镜像翻转，并可配置面部特征以实现视线跟随。
* 🎭 **Live2D 模型 (可选)**：支持完整的 Live2D 动态模型渲染（兼容 Cubism 2 的 `model.json` 和 Cubism 3 的 `.model3.json`），支持模型自带动作触发与视线跟随。

### 2. 沉浸式桌面交互
* **无边框与透明背景**：完美融入桌面环境。
* **物理重力引擎**：鼠标拖拽松手后，宠物会受重力影响自然掉落到底部或任务栏上方。
* **边缘吸附与隐藏**：将宠物拖至屏幕边缘（左、右、上）可自动吸附并缩回隐藏，鼠标靠近时会自动探出。
* **动作反馈**：支持通过点击触发内置的窗口动作（如起跳、蹦跳、点头、摇头、转身、跳舞等）。
* **防遮挡机制**：支持设置“鼠标穿透”和“避开任务栏”。

### 3. 伴侣、雌小鬼与养成系统 (Personality & Affinity)
通过内置的配置系统，你可以让宠物拥有不同的“性格”：
* **普通气泡**：宠物会根据设定的频率随机弹出日常语录。
* **伴侣模式 (Companion Mode)**：开启后，气泡内容将切换为情侣专属语录（告白、情话、打情骂俏等）。
* **雌小鬼模式 (Mesugaki Mode)**：开启后，宠物会以傲娇、调侃的语气与你互动。
* **养成模式 (Nurture Mode)**：引入好感度系统，随着陪伴时长的增加、日常的互动（如摸头），好感度会逐渐提升，解锁不同阶段的专属台词。
* **节日问候**：支持配置用户生日与自定义纪念日，在特定日子宠物会送上专属问候。

### 4. 语音与 TTS 朗读
* **Live2D 原生语音**：在触发特定动作（如摸头、戳身体）时，播放模型自带的 `.wav` 语音。
* **TTS 系统朗读**：基于系统自带的 Text-To-Speech 服务 (QtTextToSpeech)，支持将气泡文本用语音读出来。支持调整音量、语速，甚至接入自定义的 TTS 后端命令。

## 🚀 安装与运行

### 1. 环境要求
* **操作系统**：Windows 10 / 11
* **Python 版本**：Python 3.8 或更高版本

### 2. 依赖安装
在项目根目录下打开终端，执行以下命令安装基础依赖：

```bash
pip install -r requirements.txt
```

核心依赖项包括：
* `PySide6 >= 6.6` （UI 框架与核心功能）
* `pygame >= 2.0.0` （音频与音效播放支持）
* `send2trash >= 1.8.0` （文件回收站操作支持）

### 3. 可选功能配置 (Live2D 支持)
> **⚠️ 注意：Live2D 为可选功能。**
如果你不需要 Live2D 模型，项目依然可以以像素宠物或图片宠物完美运行。

如果需要加载 Live2D 模型，你需要额外安装 `live2d-py` 库：
```bash
pip install live2d-py
```
**配置模型数据：**
将你的 Live2D 模型文件夹放置在项目根目录的 `live2d/` 文件夹下（或通过设置自定义的模型路径）。如果是常用的模型，可以将其放入 `live2d/常用/` 目录下，以便在应用内的模型选择器中置顶显示。

### 4. 启动应用
安装完依赖后，运行以下命令启动桌面宠物：
```bash
python main.py
```
你也可以直接双击项目目录下的 `启动桌面宠物.bat` 来启动。

## 🐋 鲸鱼娘（完整精灵动作）

右键宠物或托盘 → **切换形象 → 鲸鱼娘 · 大肥鱼（完整动作）**。
无需配置 API Key，也不需要安装新的依赖。它是多帧精灵角色，不是 Live2D 模型。

- **全部动作**：右键 →「鲸鱼娘动作（全部）」。18 个状态、28 组素材、67 张公开最高分辨率帧全部接入。
- **互动**：点头部摸头、点身体反馈、点右侧尾部甩尾、双击投喂；拖动显示抓取姿势，松手配合重力显示下落与落地。
- **行走**：动作菜单选择向左/向右走，使用独立方向帧，包含起步、四帧循环、收步；一次行走约 5 秒，边界转向。
- **睡眠与过渡**：睡觉包含入睡动作，选择其他动作时播放醒来；「过渡动作与其他视角」可单独查看背面、侧面、起步/收步、入睡/醒来和松手腾空。
- **日常动作**：默认自动眨眼、张望、思考等，可关闭「自动日常动作」；关闭后仍能手动触发全部动作。
- **尺寸与记忆**：独立保存 `whale_size`、`whale_facing`、`whale_auto_actions` 和角色尺寸记忆，不覆盖 Live2D 构图或自定义图片设置。
- **内存策略**：只解码当前需要的帧，缩放帧缓存限制为 8 MiB；隐藏停表，换模型释放缓存。这个上限不是整个应用的内存占用。

素材存放在 `assets/whale`，来源、固定上游版本及授权边界见其中的 `NOTICE.md` 和 `ASSET_LICENSE.md`。
部分动作是单张关键姿势加轻微整体动画，不能把它们说成多帧 Live2D 骨骼动作。
**代码开源不等于角色素材可以任意再发布或商用**；当前接入用于本地项目，发布前请另行确认美术授权。

## 🛠️ 打包与发布

### 快捷启动与搜索

右键宠物 / 托盘 → **快捷启动与搜索…**；也可以从 **快速启动** 子菜单直接打开前 8 个收藏。

- 默认提供记事本、计算器和文件资源管理器；「+ 程序」添加本机 `.exe` / `.lnk`，「+ 文件夹」收藏目录。
- 输入名称、文件名或自定义关键词即时筛选；「管理」可编辑名称/关键词、调整顺序和移除收藏。移除不会删除原文件。
- `↑↓` 选择、`Enter` 启动、`Ctrl+Enter` 直接网页搜索、`Ctrl+L` 回到搜索框、`Esc` 关闭。
- 可选必应、百度和 Google。**输入时仅本地筛选，不联网、不记录搜索历史；确认搜索后才把关键词交给默认浏览器。**
- 不执行输入框里的命令，不支持脚本、网络共享路径或全盘文件搜索；使用已有快捷方式可保留程序自己的启动参数。
- 收藏最多 80 项，保存在 `quick_launch_items`；搜索引擎保存在 `quick_search_engine`。旧配置自动使用默认项，用户清空列表不会重新补回。
- 面板按需创建、关闭释放，不扫描安装目录、不提取 exe 图标、不增加常驻线程或定时器。

### 自定义全局快捷键

右键宠物 / 托盘 → **快捷键设置…**，点击输入框并按下组合键：
- **显示 / 隐藏宠物**：默认 `Ctrl+Alt+P`。
- **快捷启动与搜索**：默认 `Ctrl+Alt+Space`；宠物隐藏时也能打开面板并聚焦搜索框。
- 点击输入框的清除按钮可禁用该动作；「恢复默认组合」后仍需点保存。
- 保存后立即生效，并记住 `hotkey_toggle_pet`、`hotkey_quick_panel`，旧配置自动补默认值。
- 支持带 Ctrl / Alt / Win 的单组组合键；支持字母、普通数字、功能键（F12 除外）、空格和导航键。
  数字小键盘专用组合和连续多组按键不支持。重复、系统保留或其他软件占用会提示，失败不覆盖原有注册及配置。
- 设置窗口打开时暂停执行全局快捷动作，避免录入时误触；切换置顶 / 穿透不会丢失注册，退出释放。

### Live2D 模型管理预览

- 切换列表的固定等待从 420ms 缩短至 120ms；快速连续选择仍只加载最后一项。
- 首帧就绪前加快检查，出图后回到省电的 12fps；重复选中当前模型、快速切回未释放的预览无需重载。
- 右侧 **预览画质** 独立提供「快速 1024」「清晰 2048」「原始贴图」，默认快速档。
  此选择保存在 `live2d_preview_texture_limit`，**仅影响管理界面，不改变桌面宠物画质或源模型文件**。
- 新选项尚未出图时禁用「应用」，避免把上一只模型误应用；关闭窗口会释放预览和过期回调。
- 首次缓存生成、原始贴图解码和原生模型创建仍需时间，不是所有模型都能瞬时打开。

### Live2D 画质与内存

Live2D 角色右键 → **Live2D 画质与内存**：
- **均衡 2048（默认）**：大贴图按长边 2048 生成缓存副本，适合通常只有几百像素的桌宠。
- **高清 4096**：保留更多细节，但占用高于均衡档。
- **原始画质**：直接读取原模型贴图，8K 模型占用和加载时间会较高。

这是明确的画质/资源取舍，不是无损压缩；模型放得很大时可以切回原图。
源模型、动作、表情、语音均不删改。派生纹理及模型清单保存在
`~/.desktop-pet/cache/live2d-textures`，仅后台准备图片/文件，Qt 控件和 OpenGL 仍在主线程。
缓存按源文件修改时间及大小失效，采用临时写入后发布；按最多 8 份 / 512 MiB 清理不在用的旧缓存，正在使用的缓存受保护。
缓存准备失败会回退原图，并在画质菜单标明「缓存未生效」。

尺寸调整现在只更新画布，不重复加载整套模型；连续选择会合并，旧模型回调不会作用到新模型。
拖动时复用最近一帧，只移动窗口；高频鼠标坐标、工作区查询和边界计算一起合并，
松手按最新坐标落位并恢复动画。暂停期间重显控件不会重新抓帧，不改变已有画质档位或模型资源。
性能数据和边界见 `PERFORMANCE_AUDIT.md`。验证入口另包括：
```powershell
.venv\Scripts\python.exe tests\quick_panel_smoke.py
.venv\Scripts\python.exe tests\live2d_performance.py '路径\model.json' '路径\角色.model3.json'
.venv\Scripts\python.exe tests\live2d_lifecycle_smoke.py '路径\model.json' '路径\角色.model3.json'
.venv\Scripts\python.exe tests\live2d_drag_smoke.py '路径\model.json' '路径\角色.model3.json'
.venv\Scripts\python.exe tests\live2d_picker_smoke.py '路径\model.json' '路径\角色.model3.json'
```

### 构建 Windows 程序

如果你希望将项目打包成独立的 `.exe` 可执行文件，以便在没有 Python 环境的电脑上运行：
1. 确保已安装 `pyinstaller`。
2. 双击运行 `build_exe.bat` 脚本。
3. 编译完成后，生成的程序会位于 `dist/` 文件夹中。

*(注：由于 PyInstaller 打包逻辑，如果需要附带 Live2D 预设模型，请确保 `live2d/` 文件夹位于 `dist/` 对应的相同层级，或通过配置文件指定路径。)*

## 📂 主要文件结构说明
* `main.py` - 主程序入口，包含窗口逻辑、系统托盘、边缘吸附与手势判断。
* `config.py` - 配置管理器，负责读取和保存用户设置（配置保存在 `~/.desktop-pet/config.json`）。
* `pixel_pet.py` / `image_pet.py` / `live2d_pet.py` - 不同形态宠物的具体渲染引擎。
* `chat_bubble.py` - 气泡系统逻辑及界面。
* `affinity.py` - 好感度与养成系统核心逻辑。
* `*_quotes.py` - 包含普通语录、伴侣语录、雌小鬼语录等文本数据。
* `tts_player.py` / `voice_player.py` - 系统 TTS 以及音频播放控制模块。

**💡 如何使用新模型：**
下载后解压，将整个模型文件夹（内部包含 `.model.json` 或 `.model3.json` 即可）直接复制到本项目的 `live2d` 文件夹下。重启软件或在右键菜单的“选择 Live2D 模型”中即可找到并应用。
本次为体验与稳定性修复版，未改动模型与既有功能开关：
* **流畅度**：渲染/动画改用精确定时器（PreciseTimer），消除帧间隔抖动。拖动宠物时合并高频鼠标事件，避免重合成卡顿，精确落位。
* **摸头光标**：重绘为更二次元的白手套，修复“拇指右侧缺口”。
* **猜拳气泡**：猜拳时气泡锁定位置，不再随动作抽搐。
* **模型自动贴合**：修复自动贴合导致的模型翻转、花屏等问题，预热渲染并进行有效性校验，跳过残帧。
* **看向鼠标**：修复部分 v3 模型“看向鼠标”失效问题，确定性驱动朝向参数。关闭时待机微动更自然。
